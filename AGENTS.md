# Инструкции для Codex

Проект: агентное торговое приложение для хакатона. Пишется за пять часов,
живёт один день, показывается жюри. Оптимизируй под «работает и понятно»,
а не под «расширяемо».

## Как проверять свою работу

После **любой** правки в `src/lib/` обязательно:

```bash
npm run smoke        # сквозной сценарий без сети, должен закончиться "Сценарий пройден целиком"
npx tsc --noEmit     # типы
```

Не сообщай о готовности, пока обе команды не прошли. Если смоук красный —
чини, а не объясняй, почему он красный.

## Архитектурные границы — не нарушать

1. **Ровно три инструмента.** `search_catalog`, `update_cart`, `manage_order`.
   Новый инструмент не добавлять. Нужно новое действие — новое значение
   в `action` существующего инструмента.
2. **Вся работа с БД — только в `src/lib/db.ts`.** Ни одного SQL-запроса
   в инструментах, маршрутах или компонентах.
3. **Модель вызывается только через `completeStream()`** из
   `src/lib/llm/client.ts`. Не импортируй `openai` больше нигде.
4. **Ключ, модель и лимиты — только в `src/lib/config.ts`.** Никаких
   `process.env` в других файлах, кроме `db.ts` (проверка Vercel).
5. **Агентный цикл один** — `src/lib/agent/loop.ts`. Второй цикл не заводить.
6. **Каждый инструмент валидируется zod'ом** перед исполнением, и его
   JSON Schema для модели описана рядом в `TOOL_SPECS`. Правишь одно —
   правь и второе.
7. **Записанный режим должен продолжать проходить весь сценарий.**
   Меняешь инструмент — поправь `src/lib/llm/mock.ts` и убедись смоуком.

## Стиль

- TypeScript, strict. `any` не использовать, `unknown` + сужение — можно.
- Комментарии по-русски и только там, где код не объясняет себя сам:
  почему так, а не что делает строка.
- Тексты в интерфейсе и ответы агента — по-русски, цены в тенге (`₸`).
- Не добавляй зависимости. Если кажется, что нужна библиотека — сначала
  спроси. Каждая новая зависимость это риск на деплое.
- Не заводи новые файлы без необходимости. Логика инструмента живёт
  в `tools.ts`, запрос к базе — в `db.ts`.

## Чего не делать

- Не трогать `src/lib/agent/bridge.ts` — он выглядит переусложнённым,
  но без него ломается стриминг.
- Не переводить историю диалога на сервер: сервер намеренно без состояния.
- Не переписывать SSE на `EventSource` — он не умеет POST.
- Не добавлять авторизацию, платежи, загрузку файлов.
- Не делать рефакторинг «заодно». Правь только то, о чём просят.

## Полезные факты

- Каталог: `data/products.json`, 19 товаров, 5 категорий. Засев при старте
  идемпотентный: поменял файл — перезапусти, база пересоберётся.
- Поиск токенизирует запрос и грубо обрезает слова до 5 символов
  (русские окончания). Пустая выдача -> повтор без текстового условия.
- `sessionId` генерируется на клиенте и лежит в `localStorage`.
- События цикла: `status`, `tool_call`, `tool_result`, `token`, `state`,
  `history`, `done`, `error`. Добавляешь событие — добавь и в `AgentApp.tsx`.
