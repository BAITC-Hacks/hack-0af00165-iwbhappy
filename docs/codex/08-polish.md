## Правила последнего часа — важнее пунктов ниже

1. **Пункт = коммит = пуш.** Закончил пункт → проверки → коммит → пуш
   в обе ветки. Не копить. Если время кончится посреди списка, в
   репозитории должно лежать всё сделанное до этого момента.
   `git push origin seed-from-api && git push origin seed-from-api:main`
2. **Проверки после КАЖДОГО пункта:** `npx tsc --noEmit`,
   `npm run smoke`, `npm run demo`, `npm run mock-check`. Упало —
   `git checkout -- .` и переходи к следующему пункту. Не чинить
   полчаса то, что было украшением.
3. **Жёсткий стоп за 15 минут до дедлайна.** Что бы ни было в работе —
   откатить незакоммиченное, убедиться, что `git status` чистый,
   `git log origin/main -1` совпадает с `git log -1`. Сдаётся `main`.
4. **Не деплоить.** `vercel --prod` запускает только пользователь.
   Сломанный деплой за 10 минут до защиты не откатить.
5. **`npm run build` — только если dev-сервер НЕ запущен**
   (`curl -s -o /dev/null -w "%{http_code}" http://localhost:3000`
   вернул не 200). Иначе сломаешь пользователю localhost, как в
   прошлый раз.
6. **Запрещено:** новые зависимости; менять схему БД; переименовывать
   маршруты и поля API; трогать `src/lib/agent/`, `src/lib/db.ts`,
   `src/lib/redact.ts`, `src/lib/ratelimit.ts`, `src/app/api/`,
   `data/`. Правило подтверждения (AGENTS.md §6) — не трогать ни в
   каком виде.
7. Сомневаешься, ломает ли правка поведение, — не делай её.

### 4. Интерфейс: мелочи, которые видно на демо (15 мин)

Только `src/components/*` и `src/app/globals.css`. Никакой новой логики.

- Ответ 429 (лимит) и 413 (длинное сообщение) от `/api/chat` —
  показать текст ошибки из ответа сервера в ленте, а не «HTTP 429».
  Проверь, как сейчас: скорее всего, уже показывается `error` — тогда
  пункт пропусти.
- Поле ввода: Enter — отправить, Shift+Enter — перенос строки. Если
  уже так — пропусти.
- Кнопки «Да / Нет» и «Отправить» в состоянии загрузки — `disabled`
  и видимо неактивны, чтобы нельзя было нажать дважды. Сервер двойное
  подтверждение и так отклонит, но жюри не должно видеть ошибку.
- `aria-label` у кнопок-иконок (скрепка, закрыть, новый диалог).
- На ширине 375px: ничего не вылезает по горизонтали. Проверяй по CSS
  (браузера у тебя нет) — ищи фиксированные `width` больше 340px без
  `max-width: 100%` и `white-space: nowrap` на длинных строках.
  Длинные названия товаров — `overflow-wrap: anywhere`.

### 5. `docs/ARCHITECTURE.md` со схемой (10 мин)

GitHub рисует Mermaid. Одна схема потока и одна — подтверждения:

1. Поток: браузер / виджет → `/api/chat` (SSE) → агентный цикл →

на GitHub выглядит как красная ошибка.
