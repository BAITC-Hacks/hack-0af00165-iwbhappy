КОНТРАКТ СЕРВЕРА

POST /api/chat  -> SSE, события (поле type):
  status       { phase: "thinking" | "tools" | "answering" }
  tool_call    { id, name, args }
  tool_result  { id, name, ok, summary, ms, client? }
               client приходит только у propose_add при ok === true:
               { kind: "proposal", proposalId, sku, name, qty, requestedQty,
                 price, lineTotal, available, minOrder }
               qty — сколько реально добавится (обрезано по остатку),
               requestedQty — сколько просил клиент. Если они различаются,
               в карточке это надо показать.
  token        { text }
  state        { cart }
  history      { messages }   — сохранять и слать обратно в следующем запросе
  done         { traceId, steps, ms, source, model }
  error        { message }
  Тело запроса: { sessionId, message, history }

GET  /api/state?sessionId=...
  -> { cart, demoPrompts: string[], demoSkus: {inStock, outOfStock},
       env: { llmMode, hasKey, model, catalogSize, dbEphemeral }, logs }
  demoPrompts брать отсюда и рисовать кнопками. НЕ хардкодить артикулы:
  они зависят от выгрузки и протухнут.

POST /api/confirm  { sessionId, proposalId } -> { cart, added, capped, availableQty }
  Ошибки: 409 { error, code, cart }

POST /api/reset  { sessionId } -> { cart }

Типы: Cart = { lines: CartLine[], total, count },
      CartLine = { sku, name, price, qty, lineTotal }

НУЖНО
