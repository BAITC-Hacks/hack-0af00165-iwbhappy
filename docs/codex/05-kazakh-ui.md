Задача P2 №17–18 из раздела 10 AGENTS.md: казахский язык интерфейса
и кнопка связи с менеджером.

Логическая часть уже сделана (коммит 131d549): агент отвечает на языке
клиента, матчер согласия понимает казахский («иә», «қосыңыз», «жоқ»,
«керек емес», частицы «ма/ме»), у get_terms есть тема contacts с
реальными контактами ekt.kz. Твоя часть — интерфейс.

ФАЙЛЫ: src/components/i18n.ts (новый), src/components/AgentApp.tsx,
src/components/CartPanel.tsx, src/components/ConfirmCard.tsx,
src/components/ProductGrid.tsx, src/app/cart/page.tsx, src/app/globals.css.

НУЖНО

1. Словарь `src/components/i18n.ts`: `type Lang = "ru" | "kk"` и объект
   строк для обоих языков. Все пользовательские строки интерфейса —
   оттуда: плейсхолдер ввода, кнопки, заголовки зон, подписи корзины,
   статусы («думаю», «ищу в каталоге»), тексты ошибок, подпись MOCK.

   Опорные переводы (остальное — в том же духе, коротко и естественно):
   - Корзина — Себет
   - Отправить — Жіберу
   - Да, добавить — Иә, қосу
   - Да, добавить всё — Иә, бәрін қосу
   - Нет — Жоқ
   - В наличии — Қоймада бар
   - Нет в наличии — Қоймада жоқ
   - Итого — Барлығы
   - Не нашли в каталоге — Каталогтан табылмады
   - Связаться с менеджером — Менеджермен байланысу
   - Введите вопрос или артикул — Сұрағыңызды немесе артикулды жазыңыз
   - Демонстрационный сертификат — Демонстрациялық сертификат

2. Переключатель RU / KZ в шапке. Выбор хранится в localStorage
   (чтение и запись — в try/catch, без хранилища страница обязана
   работать на русском). По умолчанию — русский.

3. Быстрые подсказки (демо-сценарий) при казахском интерфейсе — на
   казахском. Шаблоны артикулов подставляются так же, как сейчас:
   - «{SKU_IN} артикулы туралы айтыңыз: қоймада бар ма, сипаттамалары қандай, сертификаты бар ма?»
   - «{SKU_OUT} бар ма? Жоқ болса, орнына не ұсынасыз және неге?»
   - «Төлем және жеткізу шарттары қандай?»
   - «{SKU_IN} себетке қосыңыз, 2 дана»
   - «Иә, қосыңыз»
   Русские шаблоны живут в src/lib/agent/prompts.ts (DEMO_TEMPLATES) —
   их не трогай; казахские положи рядом со словарём.

4. Кнопка «Связаться с менеджером» в шапке чата. Нажатие отправляет в
   чат обычной репликой пользователя «Как связаться с менеджером?»
   (на казахском — «Менеджермен қалай байланысуға болады?»). Дальше
   агент сам вызовет get_terms(contacts). Контакты в интерфейс не
   зашивать: источник — только ответ инструмента.

5. Мобильная вёрстка не должна поехать: переключатель и кнопка менеджера
   помещаются в шапку на ширине 375px. Проверь.

НЕ ТРОГАЙ: src/lib/ целиком, src/app/api/, scripts/, data/, AGENTS.md.
Язык ответов модели выбирает сама модель по языку реплики — интерфейс
модели язык НЕ передаёт. Не добавляй для этого новых полей в /api/chat.
