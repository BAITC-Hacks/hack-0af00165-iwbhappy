Задача 06: безопасная сессия, история диалога, новые форматы вложений.

Контекст. Сверка с ТЗ §9 («защита от несанкционированного изменения
корзины», «приватность данных клиента») нашла, что sessionId — это
единственный ключ к корзине, а он (1) генерируется через Math.random и
(2) светится в ссылке на корзину. Кто получил ссылку — может через чат
с этим sessionId менять чужую корзину. Серверную часть чинит Claude
параллельно с тобой. Твоя часть — интерфейс.

ФАЙЛЫ: src/components/AgentApp.tsx, src/components/CartPanel.tsx,
src/components/i18n.ts, src/app/globals.css.

НЕ ТРОГАЙ: src/lib/ целиком, src/app/api/ целиком, src/app/cart/page.tsx,
scripts/, data/, AGENTS.md. Там сейчас работает Claude — конфликт правок
будет стоить дороже самой задачи.

НУЖНО

1. **sessionId криптостойкий.** В `makeId("session")` / `useSessionId`
   использовать `crypto.randomUUID()`. Если его нет (старый браузер,
   не-HTTPS) — `crypto.getRandomValues` на 16 байт в hex. Math.random
   для сессии не использовать вообще. Для id сообщений в ленте
   Math.random можно оставить — это не секрет.

2. **Ссылка на корзину из сервера, а не собранная в браузере.**
   Сейчас CartPanel строит `/cart?session=<sessionId>` сам. Так больше
   нельзя: в ссылке не должно быть sessionId. Сервер теперь отдаёт
   готовую ссылку в поле `cartUrl`:
   - `GET /api/state?sessionId=…` → `{ cart, cartUrl, … }`
   - `POST /api/confirm` → `{ …, cartUrl }`
   Бери `cartUrl` оттуда. Пока его нет (корзина пуста / ещё не
   загрузилось) — кнопка «Открыть корзину» неактивна.

3. **История диалога переживает перезагрузку страницы.**
   ТЗ §8: «сохранение истории диалога». Авторизации у нас нет, поэтому
   храним в браузере, в рамках сессии:
   - ключ localStorage `hackalem.chat.<sessionId>`;
   - сохраняем ленту (сообщения, карточки предложений) и историю модели,
     которую уже шлёшь в /api/chat;
   - не больше 40 элементов ленты — старые отрезаем;
   - миниатюры фото (data:-URL) НЕ сохраняем — заменяй подписью
     «[фото]»: они тяжёлые и переполнят хранилище;
   - чтение и запись — в try/catch; без хранилища страница работает
     как сейчас;
   - карточка предложения после перезагрузки показывается, но без
     кнопок, если предложение уже обработано (подтверждено или
     отклонено) — храни его статус вместе с карточкой.

4. **Кнопка «Новый диалог»** в шапке чата (kk: «Жаңа диалог»):
   `POST /api/reset { sessionId }`, затем новый sessionId, очистить
   ленту и `hackalem.chat.*` старой сессии. Подтверждение через
   `confirm()` не нужно.

5. **Вложения: Word и PDF.** В `accept` поля файла добавить
   `.docx,.pdf`. Сервер начнёт их принимать в этом же заходе. Ответ
   для них — тот же `kind: "spec"`, отдельная обработка не нужна.
   Для фото тоже может прийти `kind: "spec"` (сфотографированная
   накладная) — сейчас код на это кидает «Неизвестный ответ»?
   Проверь: `kind: "spec"` должен обрабатываться одинаково, из какого
   бы файла он ни пришёл.

sessionId. В ссылке «Открыть корзину» нет sessionId.
